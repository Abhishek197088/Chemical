# PDF Export Instructions

This folder contains the complete presentation guide and project documentation for **AasaMedChem**.

To convert the `project_presentation_guide.md` file in this folder to a clean, professional PDF:

## Method 1: Using VS Code (Recommended)
1. Install the extension **Markdown PDF** (`yzane.markdown-pdf`) inside VS Code.
2. Open `project_presentation_guide.md` in VS Code.
3. Right-click anywhere in the file editor window and select **Markdown PDF: Export (pdf)**.
4. A file named `project_presentation_guide.pdf` will be created in this folder instantly.

## Method 2: Using a Web Browser
1. Copy the contents of `project_presentation_guide.md`.
2. Paste it into an online Markdown editor like [Dillinger](https://dillinger.io/).
3. Click the **Export** or **Preview** button, select **Print**, and choose **Save as PDF** from your print options.

## Method 3: Using Typora / Obsidian
1. Open the folder in Typora, Obsidian, or any Markdown-compatible note-taking app.
2. Go to **File > Export > PDF**.
